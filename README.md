# Wolf - Producción Audiovisual

Sitio web oficial de **Wolf | Producción Audiovisual**.

## 📁 Estructura del Proyecto

- `index.html`: Página principal del sitio.
- `css/`: Hojas de estilo personalizadas (`style.css`).
- `js/`: Archivos de interactividad y comportamiento (`script.js`).
- `img/`: Recursos gráficos, logotipos e imágenes del proyecto.

## 🚀 Visualización Local

Para ver el proyecto en tu navegador:
1. Abre el archivo `index.html` directamente en tu navegador web o usa una extensión como *Live Server* en tu editor.
